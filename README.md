# Grok Cal

Voice-first calendar. Better than Google Calendar. Fits phone + desktop. Grok reminders. Edit everything by voice.

## Status
Beta skeleton — 2026-09-12.

## Spec
- Responsive: phone-first, scales to desktop.
- Voice edit: "Add SC vs Georgia Nov 21 Columbia" → event created.
- Grok reminders: push + on-device.
- Syncs with Google Calendar (source of truth for now).
- Dark theme, Lathom-style.

## Roadmap
1. Skeleton UI (this commit)
2. Voice input → event parse
3. Grok reminder bridge
4. Replace Google Calendar as primary

Live: https://grokcal.vercel.app (pending deploy)
